# Tag taxonomy

Register a tag here before using it in a shared entry. Prefer a small stable
vocabulary over near-synonyms.

## Active

- `codex` — Codex configuration and agent workflows.
- `knowledge-management` — capture, organization, maintenance, and provenance.
- `qmd` — QMD indexing and semantic retrieval.
- `retrieval` — search, ranking, context selection, and recall.
- `security` — information boundaries, secret scanning, and safe sharing.
- `visualization` — graphing, visual navigation, and knowledge topology.
- `workflow` — repeatable operational processes.
